## Jarvis 0.8.37

A run de favoritos usa a entrada do próprio Chrome para clicar em **Enfrentar**. Após uma vitória confirmada, prepara o próximo favorito e solicita uma única entrada. Confere o nome, as cargas, a disponibilidade e a posição do botão antes do clique. Para em derrota, pedido de dificuldade ou resultado incerto.

O pacote Chrome exige a nova permissão **debugger** e mostra o aviso de depuração durante a run. O controle do Jarvis fica restrito à aba do Baiak que iniciou a sequência. No Firefox, cada luta continua exigindo o clique do jogador.

Recarregue a extensão em `chrome://extensions` após atualizar os arquivos, sem recarregar o jogo. Confira **Jarvis 0.8.37 AUTO** no rodapé e use **Chefes → Iniciar run**.

Testes locais de sequência, cancelamento e proteção contra entradas duplicadas aprovados. Uma run completa de chefes favoritos foi confirmada pelo usuário no Chrome.
